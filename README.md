**Age Calculator**

A clean, minimal age calculator that tells you your exact age in years, months, and days — built with pure HTML, CSS, and vanilla JavaScript. No frameworks. No libraries. No dependencies.


**Features**


1. Calculates exact age in Years, Months, and Days
2. Full input validation with inline error messages
3. Handles edge cases — leap years, Feb 30, month-end boundaries
4. Responsive layout — works on mobile and desktop
5. Instant result — no page reload
6. Clear/Reset button to start over
7. Zero external dependencies
